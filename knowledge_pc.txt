# دليل الدعم الفني الشامل للكمبيوتر - TechSupport

# أولاً: قطع الكمبيوتر وأجزاؤه

## المعالج CPU
المعالج هو دماغ الكمبيوتر. يقوم بتنفيذ جميع العمليات الحسابية.
- Intel: Core i3 (مبتدئ), Core i5 (متوسط), Core i7 (متقدم), Core i9 (احترافي)
- AMD: Ryzen 3, Ryzen 5, Ryzen 7, Ryzen 9
- درجة الحرارة الطبيعية: 40-70 درجة عند الاستخدام العادي
- درجة الحرارة القصوى: 90-100 درجة (خطر)
- معجون الحرارة Thermal Paste يجب تغييره كل 3-5 سنوات

## الذاكرة العشوائية RAM
الذاكرة المؤقتة التي تخزن البيانات أثناء الاستخدام.
- DDR4: الأكثر شيوعاً حالياً
- DDR5: الأحدث والأسرع
- 8GB: كافي للاستخدام العادي
- 16GB: مثالي للألعاب والتصميم
- 32GB وأكثر: للمهنيين والعمل الثقيل
- أعراض مشكلة RAM: شاشة زرقاء، تجميد مفاجئ، أخطاء عشوائية

## القرص الصلب Storage
- HDD: قرص صلب تقليدي، بطيء لكن رخيص وسعة كبيرة
- SSD SATA: أسرع من HDD بـ 5-10 مرات
- SSD NVMe M.2: الأسرع، أسرع من HDD بـ 20-30 مرة
- يجب إبقاء 15-20% مساحة فارغة دائماً
- عمر HDD: 5-7 سنوات
- عمر SSD: 7-10 سنوات

## كرت الشاشة GPU
- مدمج Integrated: يكفي للاستخدام العادي والمكتبي
- مستقل Dedicated: للألعاب والتصميم والفيديو
- NVIDIA: GeForce GTX, RTX
- AMD: Radeon RX
- درجة حرارة GPU الطبيعية: 60-80 درجة
- القصوى: 90-95 درجة

## اللوحة الأم Motherboard
- تربط جميع مكونات الجهاز
- يجب التأكد من التوافق مع المعالج والذاكرة
- تحتوي على BIOS/UEFI للإعدادات الأساسية

## مزود الطاقة PSU
- يوفر الكهرباء لجميع المكونات
- يجب اختيار واط مناسب للمكونات
- علامة 80 Plus تدل على الكفاءة
- PSU رديء يمكنه تلف جميع مكونات الجهاز

## التبريد Cooling
- مروحة هواء Air Cooler: كافية للاستخدام العادي
- تبريد مائي Water Cooling: للأداء العالي
- يجب تنظيف المراوح كل 6 أشهر

# ثانياً: مشاكل الأداء وحلولها

## الكمبيوتر بطيء

### الأسباب الشائعة:
- كثرة البرامج في Startup
- ذاكرة RAM ممتلئة
- القرص الصلب ممتلئ أو بطيء
- وجود فيروسات وبرامج ضارة
- نظام التشغيل قديم
- درجة حرارة عالية تسبب التباطؤ Thermal Throttling
- تراكم الملفات المؤقتة

### الحلول خطوة بخطوة:
1. افتح Task Manager بـ Ctrl+Shift+Esc وأغلق البرامج الثقيلة
2. اذهب لـ Startup في Task Manager وأوقف البرامج غير الضرورية
3. شغّل Disk Cleanup لحذف الملفات المؤقتة
4. في CMD كمسؤول اكتب: cleanmgr /sageset:1
5. افحص القرص بـ: chkdsk C: /f /r
6. تأكد من تحديث Windows
7. افحص الجهاز من الفيروسات
8. إذا استمر البطء فكر في إضافة RAM أو تغيير HDD إلى SSD

## الكمبيوتر يتجمد Freeze

### الأسباب:
- مشكلة RAM
- مشكلة في القرص الصلب
- ارتفاع درجة الحرارة
- تعريفات قديمة أو تالفة
- مشكلة في PSU

### الحلول:
1. شغّل Windows Memory Diagnostic للتحقق من RAM
2. افحص القرص: chkdsk C: /f
3. تحقق من درجة الحرارة بـ HWMonitor
4. حدّث جميع التعريفات
5. تحقق من Event Viewer لمعرفة سبب التجميد

## الكمبيوتر يعيد التشغيل تلقائياً

### الأسباب:
- ارتفاع حرارة المعالج
- مشكلة في PSU
- مشكلة في Windows
- تحديث تالف

### الحلول:
1. تحقق من درجة الحرارة
2. نظّف المراوح
3. في CMD: sfc /scannow
4. تحقق من سجل الأحداث في Event Viewer
5. إذا بدأ بعد تحديث: تراجع عن التحديث

# ثالثاً: مشاكل الشاشة الزرقاء BSOD

## رموز الخطأ الشائعة:

### MEMORY_MANAGEMENT
- السبب: مشكلة في RAM
- الحل: شغّل Windows Memory Diagnostic، جرب نزع أحد عصي الرام وتشغيل الجهاز بعصا واحدة

### CRITICAL_PROCESS_DIED
- السبب: ملفات نظام تالفة أو تعريف تالف
- الحل: sfc /scannow، DISM /Online /Cleanup-Image /RestoreHealth

### IRQL_NOT_LESS_OR_EQUAL
- السبب: تعريف غير متوافق
- الحل: حدّث أو أزل التعريف المشكلة

### DRIVER_POWER_STATE_FAILURE
- السبب: مشكلة في تعريف الطاقة
- الحل: حدّث تعريفات كرت الشاشة والشبكة

### PAGE_FAULT_IN_NONPAGED_AREA
- السبب: مشكلة RAM أو تعريف
- الحل: فحص RAM، تحديث التعريفات

### NTFS_FILE_SYSTEM
- السبب: مشكلة في القرص الصلب
- الحل: chkdsk C: /f /r

## خطوات عامة لحل BSOD:
1. لاحظ رمز الخطأ ودوّنه
2. أعد التشغيل وادخل Safe Mode بـ F8
3. شغّل: sfc /scannow في CMD كمسؤول
4. شغّل: DISM /Online /Cleanup-Image /RestoreHealth
5. حدّث أو أزل آخر برنامج أو تعريف ثبّته
6. شغّل Windows Memory Diagnostic
7. افحص القرص: chkdsk /f /r

# رابعاً: مشاكل الإنترنت والشبكة

## لا يوجد إنترنت

### الأسباب:
- مشكلة في الراوتر
- مشكلة في إعدادات الشبكة
- تعريف الشبكة تالف
- مشكلة عند مزود الخدمة ISP

### الحلول:
1. أعد تشغيل الراوتر (افصله 30 ثانية)
2. تحقق إذا أجهزة أخرى متصلة
3. اذهب لـ Settings > Network > Troubleshoot
4. في CMD كمسؤول:
   - netsh winsock reset
   - netsh int ip reset
   - ipconfig /flushdns
   - ipconfig /release
   - ipconfig /renew
5. أعد تشغيل الجهاز
6. إذا استمر: أعد تثبيت تعريف الشبكة

## الإنترنت بطيء

### الأسباب:
- بُعد عن الراوتر
- كثرة المتصلين على الشبكة
- تحميل برامج في الخلفية
- مشكلة عند مزود الخدمة

### الحلول:
1. اقترب من الراوتر أو استخدم كابل Ethernet
2. تحقق من سرعة الإنترنت على speedtest.net
3. أغلق البرامج التي تستهلك الإنترنت في الخلفية
4. تحقق من إعدادات QoS في الراوتر
5. أعد تشغيل الراوتر

## الواي فاي لا يظهر

### الحلول:
1. تأكد من تفعيل Wifi في الجهاز
2. في Device Manager تحقق من تعريف الواي فاي
3. في CMD: netsh wlan show drivers
4. أعد تثبيت تعريف الواي فاي

## مشكلة DNS

### الحل:
1. غيّر DNS إلى 8.8.8.8 (Google) أو 1.1.1.1 (Cloudflare)
2. في Network Settings > Adapter Properties > IPv4

# خامساً: الفيروسات والأمان

## أنواع البرامج الضارة:

### الفيروس Virus
- يلتصق بالملفات وينتشر
- يمكنه حذف أو تعديل الملفات

### حصان طروادة Trojan
- يتنكر كبرنامج شرعي
- يفتح باباً خلفياً للهاكر

### برنامج الفدية Ransomware
- يشفر ملفاتك ويطلب فدية
- خطير جداً ويصعب إزالته

### برامج التجسس Spyware
- يراقب نشاطك ويسرق بياناتك
- يبطئ الجهاز

### الإعلانات الضارة Adware
- يعرض إعلانات مزعجة
- يغير إعدادات المتصفح

## علامات الإصابة:
- الجهاز بطيء فجأة
- ظهور إعلانات غير مألوفة
- تغير الصفحة الرئيسية للمتصفح
- ملفات تحذف أو تتعدل وحدها
- برامج تفتح وحدها
- استهلاك عالي للإنترنت بدون سبب

## خطوات إزالة الفيروسات:
1. افصل الجهاز عن الإنترنت
2. أعد التشغيل في Safe Mode
3. شغّل Windows Defender فحص كامل Full Scan
4. حمّل وشغّل Malwarebytes
5. حمّل وشغّل AdwCleaner لإزالة Adware
6. غيّر كلمات المرور من جهاز آخر
7. تحقق من إضافات المتصفح وأزل المشبوهة

## الحماية الوقائية:
- لا تحمّل برامج من مصادر غير رسمية
- لا تفتح مرفقات الإيميل من مجهولين
- استخدم Windows Defender أو برنامج حماية موثوق
- حدّث Windows بانتظام
- استخدم كلمات مرور قوية ومختلفة
- فعّل التحقق بخطوتين
- لا تتصل بواي فاي عام بدون VPN
- احتفظ بنسخة احتياطية من بياناتك

# سادساً: مشاكل الحرارة Overheating

## درجات الحرارة الطبيعية:
- معالج في الراحة: 30-50 درجة
- معالج تحت الضغط: 60-80 درجة
- معالج قصوى: 90-100 درجة (خطر)
- GPU في الراحة: 30-45 درجة
- GPU تحت الضغط: 65-85 درجة

## أسباب ارتفاع الحرارة:
- تراكم الغبار على المراوح والمشتتات
- معجون حرارة قديم أو جاف
- تهوية سيئة للجهاز
- مروحة تالفة
- ضغط عالي مستمر على المعالج

## الحلول:
1. حمّل HWMonitor أو Core Temp لمراقبة الحرارة
2. نظّف المراوح بهواء مضغوط كل 6 أشهر
3. تأكد من وضع الجهاز في مكان جيد التهوية
4. للابتوب: لا تضعه على سرير أو وسائد
5. استخدم حامل تبريد للابتوب
6. إذا استمر: غيّر معجون الحرارة
7. تحقق من عمل جميع المراوح

# سابعاً: مشاكل التشغيل

## الجهاز لا يشتغل - لا صوت لا صورة

### الأسباب:
- مشكلة في PSU
- مشكلة في اللوحة الأم
- مشكلة في RAM

### الحلول:
1. تحقق من كابل الكهرباء
2. جرب مقبس كهرباء آخر
3. اضغط Power 10 ثوانٍ لإعادة ضبط الطاقة
4. للابتوب: افصل الشاحن والبطارية ثم أعد التركيب
5. تحقق من مؤشر LED على اللوحة الأم

## أصوات بيب عند التشغيل:
- بيب واحد: تشغيل طبيعي
- بيبين: خطأ في POST
- 3 بيبات: مشكلة RAM
- بيبات متكررة: مشكلة خطيرة في الهاردوير

## الجهاز يشتغل لكن لا توجد صورة:
1. تحقق من كابل الشاشة
2. تحقق من أن الشاشة تعمل (جربها على جهاز آخر)
3. جرب منفذ آخر HDMI/VGA/DisplayPort
4. إذا لديك كرت شاشة مستقل: جرب المنفذ المدمج
5. تحقق من إعدادات العرض بـ Windows+P

## Windows لا يبدأ:
1. أعد التشغيل مرات
2. اختر Startup Repair من قائمة التشغيل
3. في Safe Mode: شغّل sfc /scannow
4. جرب Last Known Good Configuration
5. استخدم نقطة استعادة System Restore

# ثامناً: مشاكل الشاشة

## الشاشة سوداء مع تشغيل الجهاز:
1. تحقق من كابل الشاشة
2. تحقق من مصدر الطاقة للشاشة
3. جرب كابلاً آخر
4. في الكيبورد: Windows+Ctrl+Shift+B لإعادة تشغيل الشاشة
5. تحقق من إعدادات العرض

## الشاشة تحتوي على خطوط:
- خطوط عمودية أو أفقية تدل على مشكلة في الشاشة نفسها
- جرب الشاشة على جهاز آخر
- إذا ظهرت الخطوط على جهاز آخر: الشاشة تالفة
- إذا لم تظهر: مشكلة في كرت الشاشة أو الكابل

## الشاشة تومض Flickering:
- تحقق من معدل التحديث Refresh Rate في إعدادات العرض
- حدّث تعريف كرت الشاشة
- جرب كابل آخر
- قد تكون مشكلة في PSU

## الألوان غير صحيحة:
- اذهب لـ Display Settings > Color Calibration
- تحقق من إعدادات الشاشة نفسها
- حدّث تعريف كرت الشاشة

# تاسعاً: مشاكل الطابعة

## الطابعة لا تطبع:

### الأسباب:
- ورق عالق
- حبر فارغ أو جاف
- تعريف غير صحيح
- قائمة الطباعة متوقفة

### الحلول:
1. تحقق من وجود ورق عالق وأزله بحذر
2. تحقق من مستوى الحبر أو الحبر الجاف
3. في Windows: Services > Print Spooler > Restart
4. احذف جميع مهام الطباعة العالقة
5. أعد تشغيل الطابعة والكمبيوتر
6. احذف تعريف الطابعة وأعد تثبيته

## الطباعة بجودة رديئة:
1. نظّف رأس الطباعة من خيارات الطابعة
2. اطبع صفحة اختبار
3. تحقق من مستوى الحبر
4. تأكد من استخدام ورق مناسب

## الطابعة غير متصلة:
1. تحقق من كابل USB أو اتصال الواي فاي
2. تأكد من تشغيل الطابعة
3. في Device Manager تحقق من حالة الطابعة
4. أعد تثبيت التعريف

# عاشراً: الصيانة الدورية

## الصيانة الأسبوعية:
- حذف ملفات التنزيل غير الضرورية
- إفراغ سلة المهملات
- تحديث برامج الحماية

## الصيانة الشهرية:
- تشغيل Disk Cleanup
- تحديث Windows
- فحص الجهاز من الفيروسات
- مراجعة البرامج في Startup
- النسخ الاحتياطي للملفات المهمة

## الصيانة كل 6 أشهر:
- تنظيف المراوح والفتحات بهواء مضغوط
- تحديث جميع التعريفات
- فحص القرص الصلب: chkdsk

## الصيانة السنوية:
- تغيير معجون الحرارة
- تنظيف داخلي شامل للحاسب المكتبي
- إعادة تقييم مساحة التخزين
- مراجعة حالة البطارية للابتوب

## أدوات الصيانة المجانية الموصى بها:
- HWMonitor: مراقبة الحرارة والجهد
- CrystalDiskInfo: صحة القرص الصلب
- CPU-Z: معلومات المعالج والذاكرة
- GPU-Z: معلومات كرت الشاشة
- Malwarebytes: فحص البرامج الضارة
- CCleaner: تنظيف الملفات المؤقتة (استخدم بحذر)
- Speccy: معلومات شاملة عن الجهاز

# حادي عشر: مشاكل البطارية (اللابتوب)

## البطارية تفرغ بسرعة:
1. اخفض سطوع الشاشة
2. فعّل وضع توفير الطاقة Power Saver
3. أغلق البرامج غير الضرورية
4. أوقف Bluetooth والواي فاي إذا لم تحتجهم
5. افحص البرامج التي تستنزف البطارية في Task Manager

## البطارية لا تشحن:
1. تحقق من كابل الشاحن
2. جرب منفذ شحن آخر
3. نظّف منفذ الشحن
4. تحقق من تعريف البطارية في Device Manager
5. قد تحتاج استبدال البطارية إذا عمرها أكثر من 3 سنوات

## صحة البطارية:
- في CMD: powercfg /batteryreport
- سيولّد تقرير شامل عن حالة البطارية

# ثاني عشر: مشاكل الصوت

## لا يوجد صوت:
1. تحقق من مستوى الصوت في Taskbar
2. تحقق من اختيار الجهاز الصحيح في Sound Settings
3. في Device Manager تحقق من تعريف الصوت
4. شغّل Windows Audio في Services
5. أعد تثبيت تعريف الصوت

## الصوت ضعيف أو مشوّه:
1. تحقق من إعدادات الإيكو والتحسينات في Sound Properties
2. حدّث تعريف الصوت
3. تحقق من كابلات السماعات
4. جرب سماعات أخرى

# ثالث عشر: مشاكل الكيبورد والماوس

## الكيبورد لا يعمل:
1. تحقق من الاتصال (USB أو Bluetooth)
2. جرب منفذ USB آخر
3. أعد تشغيل الجهاز
4. في Device Manager تحقق من حالة الكيبورد
5. جرب كيبورد آخر للتأكد من المشكلة

## مفاتيح معينة لا تعمل:
1. نظّف الكيبورد بهواء مضغوط
2. تحقق من إعدادات لغة الكيبورد
3. قد تحتاج استبدال الكيبورد

## الماوس لا يعمل أو غير دقيق:
1. نظّف سطح الماوس وأسفله
2. استخدم على سطح مناسب (ليس زجاج)
3. غيّر البطاريات إذا لاسلكي
4. تحقق من الاتصال
5. حدّث تعريف الماوس

# رابع عشر: استرداد البيانات

## حذف ملفات بالخطأ:
1. ابحث في سلة المهملات أولاً
2. استخدم برنامج Recuva للاسترداد
3. لا تثبّت برامج جديدة على نفس القرص (تقلل فرص الاسترداد)
4. استخدم Previous Versions في Windows إذا فعّلت File History

## القرص الصلب تالف:
1. لا تحاول الإصلاح بنفسك على قرص تالف مادياً
2. استخدم برامج مثل Recuva أو TestDisk
3. للحالات الحرجة: متخصصو استرداد البيانات

## النسخ الاحتياطي:
- استخدم Windows Backup
- احتفظ بنسخة على هارد خارجي
- استخدم خدمات سحابية: OneDrive, Google Drive
- قاعدة 3-2-1: 3 نسخ، 2 وسائط مختلفة، 1 خارج المنزل

# خامس عشر: أوامر CMD المهمة

## أوامر إصلاح النظام:
- sfc /scannow → فحص وإصلاح ملفات النظام
- DISM /Online /Cleanup-Image /RestoreHealth → إصلاح صورة Windows
- chkdsk C: /f /r → فحص القرص وإصلاح الأخطاء
- bootrec /fixmbr → إصلاح سجل التمهيد
- bootrec /fixboot → إصلاح ملفات الإقلاع

## أوامر الشبكة:
- ipconfig /all → عرض معلومات الشبكة
- ipconfig /release → تحرير عنوان IP
- ipconfig /renew → تجديد عنوان IP
- ipconfig /flushdns → مسح DNS Cache
- netsh winsock reset → إعادة ضبط Winsock
- ping 8.8.8.8 → اختبار الاتصال بالإنترنت
- tracert google.com → تتبع مسار الاتصال

## أوامر مفيدة:
- msconfig → إعدادات التشغيل
- devmgmt.msc → إدارة الأجهزة
- services.msc → إدارة الخدمات
- eventvwr → عارض الأحداث
- resmon → مراقب الموارد
- perfmon → مراقب الأداء
- winver → معلومات Windows

# سادس عشر: معلومات Windows

## إصدارات Windows:
- Windows 10: لا يزال مدعوماً حتى 2025
- Windows 11: المتطلبات أعلى، يحتاج TPM 2.0

## متطلبات Windows 11:
- معالج 1GHz أو أسرع بنواتين
- RAM 4GB كحد أدنى
- تخزين 64GB كحد أدنى
- TPM 2.0
- Secure Boot

## تحديث Windows:
- Settings > Windows Update
- التحديثات ضرورية للأمان والاستقرار
- يمكن تأخير التحديثات لكن لا تلغيها نهائياً

## أهمية التعريفات:
التعريفات هي البرامج التي تتيح للنظام التواصل مع الأجهزة.

## تحديث التعريفات:
- Device Manager: كليك يمين على الجهاز > Update Driver
- موقع الشركة المصنعة للجهاز
- Intel Driver Support Assistant
- AMD Adrenalin (لكروت AMD)
- NVIDIA GeForce Experience (لكروت NVIDIA)

## التعريفات المهمة:
- تعريف كرت الشاشة: أهم تعريف
- تعريف الشبكة: للإنترنت
- تعريف الصوت: للصوت
- تعريف Chipset: للوحة الأم

# ثامن عشر: BIOS وUEFI

## الدخول للـ BIOS:
- اضغط عند بدء التشغيل: F2, F10, F12, Del, Esc (حسب الشركة)
- Dell: F2 أو F12
- HP: F10 أو Esc
- Lenovo: F1 أو F2
- ASUS: F2 أو Del

## إعدادات مهمة في BIOS:
- Boot Order: ترتيب الإقلاع
- Secure Boot: للأمان
- XMP Profile: لتفعيل سرعة RAM الكاملة
- Virtualization: للأجهزة الافتراضية

## تحديث BIOS:
- خطوة متقدمة وخطيرة
- لا تحدّث BIOS إلا إذا كان هناك سبب محدد
- تأكد من الطاقة الكاملة أثناء التحديث

# تاسع عشر: الحماية والأمان المتقدم

## كلمات المرور:
- استخدم كلمات مرور طويلة (+12 حرف)
- اخلط أحرف كبيرة وصغيرة وأرقام ورموز
- لا تستخدم نفس الكلمة لحسابات مختلفة
- استخدم Password Manager مثل Bitwarden

## التحقق بخطوتين 2FA:
- فعّله على جميع حساباتك المهمة
- أفضل من رسائل SMS: تطبيق Authenticator

## جدار الحماية Firewall:
- Windows Firewall مفعّل افتراضياً
- لا تعطّله إلا إذا كنت متأكداً
- يمنع الاتصالات غير المصرح بها

## VPN:
- يشفر اتصالك بالإنترنت
- مفيد على شبكات عامة
- لا يوفر حماية كاملة من الفيروسات

# عشرون: أسئلة شائعة

## هل يجب إيقاف الكمبيوتر كل يوم؟
- الإيقاف يطيل عمر المكونات
- يحرر الذاكرة ويحل مشاكل صغيرة
- وضع Sleep مقبول للاستخدام اليومي
- Hibernate أفضل من Sleep للتوفير الكامل

## كم مرة يجب تنظيف الجهاز؟
- اللابتوب: كل 6-12 شهر
- الحاسب المكتبي: كل 3-6 أشهر
- البيئات المغبرة: أكثر من ذلك

## هل يجب تفريغ البطارية كاملاً قبل الشحن؟
- لا، هذا للبطاريات القديمة Ni-Cd
- بطاريات Lithium الحديثة لا تحتاج ذلك
- الأفضل: اشحن بين 20-80%

## هل برامج تسريع الكمبيوتر مفيدة؟
- معظمها وهم أو ضار
- الأفضل: استخدم أدوات Windows المدمجة
- Disk Cleanup, Startup Manager, Task Manager

## كيف أعرف إذا جهازي يحتاج ترقية؟
- إذا كان بطيئاً رغم الصيانة
- RAM أقل من 8GB
- HDD بدل SSD
- معالج أقدم من 5 سنوات للألعاب والتصميم
