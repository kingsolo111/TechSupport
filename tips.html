01

Restart first, open Task Manager and close heavy processes. Disable startup programs and clear temporary files from %temp%.

02

Restart your router (unplug 30 sec). Check other devices. Run Network Troubleshooter or reset TCP/IP via command prompt.

03

Note the error code. Run Windows Memory Diagnostic. Update all drivers via Device Manager and check Event Viewer logs.

04

Clean fan vents with compressed air. Check CPU temp with HWMonitor. Apply new thermal paste if temps exceed 90°C consistently.

05

Disconnect from internet. Run Windows Defender full scan. Download Malwarebytes for a second opinion. Change passwords after cleaning.

06

Run installer as Administrator. Ensure Windows is up to date and you have enough disk space. Temporarily disable antivirus if needed.

07

Check power cable and outlet. For laptops, remove battery and hold power button 30 sec. Try a different charger if available.

08

Use Windows Recovery options at startup. For online accounts, use the "Forgot Password" option. Enable 2FA to prevent future lockouts.

Use a mix of letters, numbers, and symbols. Never reuse passwords. Consider a password manager like Bitwarden.

Enable automatic Windows updates. Outdated software is the #1 entry point for hackers and malware.

Never access banking or sensitive accounts on public networks. Use a VPN if you must connect to public Wi-Fi.

Follow the 3-2-1 rule: 3 copies, 2 different media, 1 offsite (cloud). Use OneDrive, Google Drive, or an external drive.

Don't click links in unexpected emails. Verify the sender's email address. Legitimate companies never ask for passwords via email.

Turn on 2FA for all important accounts — email, banking, social media. Use an authenticator app for best security.
